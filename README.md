# STEP Viewer RedOwl

Высокопроизводительный веб-просмотрщик CAD-моделей (форматы STEP/STP), работающий полностью в браузере. Проект обеспечивает профессиональную визуализацию, точные измерения и анализ сечений без необходимости отправки файлов на сервер.

## Технологический стек

Проект построен на современных веб-технологиях с акцентом на производительность и нулевые зависимости от тяжелых UI-фреймворков:

- **Язык**: Vanilla JavaScript (ES6+ Modules)
- **3D-рендеринг**: Three.js (включая Post-processing и Raycasting)
- **Парсинг CAD-геометрии**: `occt-import-js` (OpenCASCADE Technology, скомпилированный в WebAssembly)
- **Сборка и разработка**: Vite
- **Стилизация**: Нативный CSS3 (без препроцессоров для максимальной легкости встраивания)
- **Управление состоянием**: Собственная модульная архитектура на базе классов (OOP)

## Ключевые возможности

- **Локальная обработка**: Файлы STEP парсятся напрямую в браузере через WebAssembly. Данные не покидают устройство пользователя.
- **Множественные экземпляры**: Поддержка любого количества независимых вьюеров на одной HTML-странице через конфигурацию data-атрибутами.
- **Профессиональная визуализация**: 
  - Автоматическая отрисовка четких CAD-контуров (sharp edges) на всех гранях модели.
  - Переключаемая отображаемая сетка триангуляции.
- **Модуль "Размеры"**: 
  - Выделение отдельных деталей кликом.
  - Отображение точных габаритов (X, Y, Z) в миллиметрах.
  - Визуализация 3D-линеек с рисками вокруг выделенного объекта или всей сборки.
- **Модуль "Разрез"**: 
  - Сечение модели по осям X, Y или Z с помощью ползунка (2% - 98%).
  - Корректное заполнение плоскости среза (stencil capping) без артефактов мерцания (z-fighting).
  - Автоматическая отрисовка контуров внутреннего сечения непосредственно на плоскости разреза.
- **Адаптивный UI**: Сворачиваемые панели инструментов, оптимизированные для работы как на десктопе, так и на мобильных устройствах.

## Быстрый старт

Для локальной разработки и тестирования выполните следующие команды в терминале:

1. Установка зависимостей:
   ```bash
   npm install
   ```

2. Запуск локального сервера разработки:
   ```bash
   npm run dev
   ```

3. Откройте в браузере адрес, указанный в терминале (обычно `http://localhost:3000`).

## Интеграция в проект

Вьюер спроектирован для максимально простого встраивания в существующие сайты. Достаточно добавить HTML-контейнер и подключить скрипт:

```html
<div class="step-viewer" data-model-url="/models/part.step" data-auto-load="true" style="width: 100%; height: 500px;">
  <div class="viewer-container"></div>
  <div class="ui-container">
    <div class="loading-overlay">
      <div class="spinner"></div>
      <div class="loading-text">Загрузка модели...</div>
      <div class="loading-progress">Пожалуйста, подождите</div>
    </div>
  </div>
</div>

<script type="module" src="/src/main.js"></script>
```
