# Справка по использованию STEP Viewer RedOwl

## Структура HTML вьюера

Каждый вьюер представляет собой блок с классом `step-viewer` и обязательной внутренней структурой:

```html
<div class="step-viewer" 
     data-model-url="" 
     data-auto-load="false"
     id="unique-viewer-id">
  <div class="viewer-container"></div>
  <div class="ui-container">
    <div class="loading-overlay">
      <div class="spinner"></div>
      <div class="loading-text">Загрузка модели...</div>
      <div class="loading-progress">Пожалуйста, подождите</div>
    </div>
  </div>
</div>
```

## Data-атрибуты

| Атрибут | Тип | Обязательный | Описание |
|---------|-----|--------------|----------|
| `data-model-url` | string | Нет | URL STEP файла для автоматической загрузки |
| `data-auto-load` | "true" / "false" | Нет | Режим загрузки. По умолчанию "false" |
| `id` | string | Нет | Уникальный идентификатор вьюера |

## Режимы работы

После загрузки модели в правом верхнем углу появляется выпадающий список для переключения между тремя режимами:

### 1. Режим "Просмотр" (View)
Режим по умолчанию. 
- Модель отображается с профессиональными черными CAD-контурами на всех острых гранях и границах.
- В левом нижнем углу доступна панель "Инструменты" с чекбоксом **"Показать сетку"** (включен по умолчанию). Сетка отображает внутреннюю триангуляцию модели.
- Поддерживается вращение, масштабирование и панорамирование.

### 2. Режим "Размеры" (Dimensions)
Позволяет измерять габариты отдельных частей или всей модели.
- При клике на деталь она выделяется бледно-оранжевым цветом.
- В левом нижнем углу появляется панель с точными размерами (Ширина X, Высота Y, Глубина Z) в миллиметрах и 3D-линейками с рисками вокруг детали.
- Кнопка **"Показать общие габариты"** сбрасывает выделение детали и показывает размеры и линейки для всей модели целиком.
- Панель размеров можно свернуть, кликнув по её заголовку.

### 3. Режим "Разрез" (Slice)
Позволяет просмотреть модель в сечении.
- В левом нижнем углу появляется панель управления разрезом.
- **Ось разреза:** выбор плоскости сечения (X, Y или Z).
- **Позиция среза:** ползунок от 2% до 98%, гарантирующий, что модель никогда не исчезнет полностью.
- Плоскость среза заполняется серой "крышкой" без артефактов мерцания (z-fighting).
- На самой плоскости среза автоматически отрисовываются черные контурные линии, точно повторяющие форму внутреннего сечения модели.

## Режимы загрузки

### Автоматическая загрузка
Модель загружается сразу при открытии страницы. Интерфейс ручной загрузки полностью скрывается.

```html
<div class="step-viewer" 
     data-model-url="/models/sample.step" 
     data-auto-load="true"
     id="viewer-auto">
  <!-- внутренняя структура -->
</div>
```
*Примечание: При ошибке загрузки по URL интерфейс ручной загрузки разблокируется автоматически.*

### Ручная загрузка
Пользователь самостоятельно выбирает STEP файл через появившуюся панель загрузки. Можно загружать разные модели последовательно.

```html
<div class="step-viewer" 
     data-auto-load="false"
     id="viewer-manual">
  <!-- внутренняя структура -->
</div>
```

## Множественные вьюеры на одной странице

Вьюеры полностью независимы. Вы можете размещать их в любых HTML-контейнерах (flex, grid, и т.д.).

### Пример: Сетка из двух вьюеров
```html
<div style="display: flex; height: 100vh;">
  <div class="step-viewer" data-model-url="/models/m1.step" data-auto-load="true" id="v1" style="width: 50%;">
    <div class="viewer-container"></div>
    <div class="ui-container">
      <div class="loading-overlay">
        <div class="spinner"></div>
        <div class="loading-text">Загрузка...</div>
        <div class="loading-progress">Пожалуйста, подождите</div>
      </div>
    </div>
  </div>

  <div class="step-viewer" data-auto-load="false" id="v2" style="width: 50%;">
    <div class="viewer-container"></div>
    <div class="ui-container">
      <div class="loading-overlay">
        <div class="spinner"></div>
        <div class="loading-text">Загрузка...</div>
        <div class="loading-progress">Пожалуйста, подождите</div>
      </div>
    </div>
  </div>
</div>
```

## Интеграция в существующий сайт

Для встраивания достаточно подключить скрипт в конце `<body>` и разместить HTML-блоки вьюеров в нужных местах страницы.

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Каталог деталей</title>
  <!-- Ваши стили -->
</head>
<body>
  <main>
    <h2>Деталь №1</h2>
    <div class="step-viewer" data-model-url="/catalog/part1.step" data-auto-load="true" style="height: 500px;">
      <div class="viewer-container"></div>
      <div class="ui-container">
        <div class="loading-overlay">
          <div class="spinner"></div>
          <div class="loading-text">Загрузка модели...</div>
          <div class="loading-progress">Пожалуйста, подождите</div>
        </div>
      </div>
    </div>
  </main>

  <!-- Скрипт инициализирует все вьюеры на странице автоматически -->
  <script type="module" src="path/to/step-viewer/src/main.js"></script>
</body>
</html>
```

## Поддерживаемые форматы
- `.step`
- `.stp`

## Важные замечания
1. Каждый вьюер на странице инициализируется и работает полностью независимо.
2. URL модели может быть как локальным (`/models/file.step`), так и удаленным (`https://example.com/file.step`), при условии корректной настройки CORS на сервере.
3. Все вьюеры автоматически инициализируются скриптом после события `DOMContentLoaded`.
4. Уникальные `id` для вьюеров рекомендуются для отладки, но не являются строго обязательными.
